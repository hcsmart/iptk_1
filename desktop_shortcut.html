바탕화면에 IPTK MES 바로가기 만들기

아래 버튼을 누르면 이 PC 바탕화면에 IPTK 로고 아이콘의 바로가기가 생깁니다.
바로가기는 평소 쓰는 브라우저(크롬·엣지 등)로 IPTK MES 를 엽니다.

윈도우 PC: 버튼을 누르면 작은 파일 IPTK_바탕화면바로가기.bat 이 받아집니다 → 브라우저 아래(또는 다운로드 폴더)에서 한 번 클릭/더블클릭 하면 바탕화면에 IPTK MES 아이콘이 생깁니다.
· 「Windows의 PC 보호」 창이 뜨면 추가 정보 → 실행 · 브라우저가 "흔하지 않은 파일" 이라고 하면 유지
휴대폰·태블릿: 버튼을 누르면 「홈 화면에 추가 / 앱 설치」 창이 뜹니다.
