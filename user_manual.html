시작하기처음 쓰는 분은 여기부터

이 시스템은 무엇을 하는가

IPTK MES는 금형 한 벌이 수주에서 납품까지 가는 동안 생기는 기록을 관리제번 하나로 묶어 관리합니다. 목적은 기록 자체가 아니라, 그 기록에서 관리제번별 실제 원가(금형원가내역)와 진척(수주진척현황)이 자동으로 나오게 하는 것입니다.

① 계획을 세운다

수주등록(개발유형 체크) → 제작계획등록 → PartList 등록.

② 실제로 만든다

설계외주·SET외주 발주, 원재료·구매품·사내외가공 발주 → 입고 → 입고확정, 설계·조립·검사 실적.

③ 결과가 자동으로 나온다

금형원가내역·매입현황·업체별 가공비·수주진척현황이 입력한 기록에서 자동 집계됩니다.

②를 빠뜨리면 ③이 조용히 틀어집니다. 이 안내가 「입고확정」과 「실적등록」을 반복해서 강조하는 이유입니다.

💡 매일 쓰는 화면은 본인 업무의 3~5개뿐입니다. 「업무 흐름 › 역할별 담당 화면」에서 본인 줄만 확인하세요.
💡 저장 결과는 화면 하단 메시지줄과 「저장됨」 팝업으로 확인합니다.

로그인과 권한

시스템 접속과 메뉴 표시 규칙입니다.

  1. 주소로 접속하면 로그인 창이 뜹니다. 사용자정보에 등록된 이메일 + 비밀번호로 로그인합니다.
  2. 로그인하면 권한이 있는 메뉴만 상단과 좌측에 표시됩니다. 필요한 메뉴가 안 보이면 관리자에게 권한을 요청하세요.
  3. 비밀번호를 잊으면 관리자가 기준정보 > 사용자정보에서 [비밀번호 재설정]으로 임시 비밀번호를 발급합니다.
💡 세션은 자동 연장되므로 업무 중 재로그인은 필요 없습니다.

화면 이동 · 탭 · 알림

상단 모듈 → 아래 아이콘(업무 묶음) → 화면 순서로 엽니다. 열린 화면은 탭으로 쌓입니다.

  1. 상단에서 모듈(영업관리·설계관리·구매관리·조립관리·원가관리·기준정보)을 누르면 메뉴판이 펼쳐집니다. 화면 이름을 누르면 탭으로 열립니다.
  2. Ctrl+K(또는 상단 「메뉴 검색」)로 화면 이름을 쳐서 바로 엽니다.
  3. ⌂ 홈에는 자주 쓰는 화면 바로가기와 공지가 있습니다.
  4. 상단 🔔은 알림(가공 공정 QR 작업완료, 제작계획 지연 등)입니다. 설정은 기준정보 › 알림등록에서 합니다.
  5. 상단 ✎ 수정요청을 누르면 수정요청게시판이 열립니다. 화면 오류·개선 요청은 여기에 남깁니다.
  6. 탭의 ×나 화면 하단 [⊠ 닫기]로 닫습니다.
💡 화면이 이상하면 먼저 새로고침(Ctrl+F5)으로 최신 화면을 받아 보세요. 수정 직후에는 옛 화면이 남아 있을 수 있습니다.

입력 화면 공통 규칙

등록/입력이 붙은 화면은 모두 같은 패턴입니다.

  1. 코드 입력칸 옆의 […] 돋보기 버튼을 누르면 조회 팝업이 뜹니다. 검색어 입력 → 행 더블클릭(또는 선택)하면 코드와 이름이 자동 입력됩니다.
  2. 목록의 행을 클릭하면 폼에 불러와져 수정 상태가 되고, [＋ 신규]를 누르면 빈 입력 상태로 돌아갑니다.
  3. [▣ 저장]은 신규면 등록, 기존 행을 불러온 상태면 수정으로 동작합니다.
  4. 삭제는 행을 선택(또는 체크)하고 [✖ 삭제] → 확인창에서 확인.
  5. 기준정보 화면 하단의 [엑셀 붙여넣기]: 엑셀에서 범위를 복사(Ctrl+C) → 버튼 클릭 → 붙여넣기(Ctrl+V) → 열 짝을 확인하고 등록하면 대량 입력이 됩니다.
  6. 저장 결과는 항상 화면 하단 메시지줄에 표시됩니다. '실패'가 뜨면 메시지의 원인(필수값 누락, 미등록 제번 등)을 확인하세요.
  7. ▼ 표시가 있는 입력칸은 드롭다운/입력 겸용입니다. 목록에서 고르거나 일부만 쳐서 거를 수 있습니다.
  8. 금액 입력칸은 치는 동안 천단위 구분기호(50,000)가 붙습니다. 저장값은 숫자입니다.
⚠ DB 미연결 상태에서는 저장·삭제가 되지 않습니다. 하단에 '미연결' 메시지가 보이면 네트워크를 확인하세요.

업무 흐름무엇이 무엇으로 이어지는가

업무 전체 순서 한눈에 보기

신규 수주 1건이 납품까지 가는 표준 경로입니다. 모든 화면이 관리제번(예 26DSA057)과 그 공정 제번(26DSA057A·B·C…)으로 이어집니다.

  1. 기준정보 — 업체관리(고객사·협력업체·양산처, 취급분야 체크), 가공공정·기준공정, 작업단가를 먼저 등록합니다.
  2. 수주등록 (영업관리) — 관리제번과 공정수를 넣어 공정 제번을 만들고, 개발유형(사내설계·외주설계·사내조립·사외조립)을 체크합니다. 외주설계면 설계업체도 적습니다.
  3. 제작계획등록 — 수주정보(양산처·설계업체 포함)를 불러와 요구/목표/가능 일정과 목표원가를 세웁니다.
  4. 외주 발주 — 외주설계 체크 제번은 설계외주발주, 사외조립 체크 제번은 SET외주발주에 나타납니다.
  5. PartList 등록 (설계관리) — 원재료·구매품 소요. 구매품은 PART LIST 엑셀파일을 그대로 불러올 수 있습니다.
  6. 원재료·구매품 발주 → 입고 → 입고확정 (구매관리) — 입고확정 때 단가·네고율로 확정가가 정해집니다. 입고확정된 금액만 원가에 들어갑니다.
  7. 사내외가공 발주 — 부품별 가공공정 표에서 외주 칸은 발주·입고, 사내 칸은 가공시간을 등록합니다. 그림보드로 공정 순서·QR 도면을 만듭니다.
  8. 설계·조립·검사 실적등록 — 작업시간(분)이 사내 노무비의 근거가 됩니다.
  9. 금형원가내역 (원가관리) — 관리제번별 재료비·가공비·공통비(외주설계·SET외주·사내설계·조립·검사·경비)가 자동 집계됩니다.
💡 진행 상황은 수주진척현황 한 화면에서 봅니다. 카드마다 「다음 조치」와 바로가기 버튼이 있습니다.

원가와 납기가 새는 곳을 막는 점검입니다.

  1. 원재료·구매품 입고확정 화면에서 「미완료」 목록을 비웁니다 — 단가·네고율·확정가를 넣고 확정.
  2. 외주가공 진척현황에서 「⚠ 지연만」·「⬚ 미발주만」으로 걸러 협력업체를 독촉합니다.
  3. 외주가공발주현황에서 구분 「입고」(확정 대기) 건을 확인합니다.
  4. 설계·조립 실적이 빠진 담당자에게 입력을 요청합니다.

월 마감 절차

원가를 확정하기 전에 이 순서대로 확인합니다.

  1. 원재료·구매품·외주가공·설계외주·SET외주의 미확정 입고를 0건으로 만듭니다. 미확정 금액은 원가에 잡히지 않습니다.
  2. 설계·조립·검사 실적과 사내가공 가공시간이 빠짐없이 들어갔는지 확인합니다.
  3. 경비등록에서 이번 달 경비가 제번에 붙었는지 확인합니다.
  4. 매입현황(구분 체크 전체)으로 매입가·확정가 합계를 확인합니다.
  5. 업체별 가공비 합계에서 [지난 달]로 업체별 정산 금액을 뽑습니다.
  6. 금형원가내역에서 관리제번별 금형 총원가를 확인하고 [▤ EXCEL]로 보고서를 만듭니다.
⚠ 마감 후에 입고확정이나 실적을 추가하면 이미 보고한 원가가 바뀝니다.

수주등록

고객 수주를 접수해 제번을 만드는 출발점입니다. 여기서 저장해야 나머지 모든 화면에 제번이 나타납니다.

  1. 관리제번(예 26DSA057)과 공정수를 넣습니다. 공정수가 2 이상이면 저장할 때 26DSA057A·B·C… 제번이 공정 수만큼 만들어지고, 「생성 제번」 칸에 미리 보입니다. 기존 관리제번을 넣으면 저장된 수주를 불러옵니다.
  2. 수주일·T/O 예정일·납기예정일, 수주상태·수주유형·국내/해외, 카테고리를 넣습니다.
  3. 아이템·담당자·고객사·금형타입·기계사양·양산처는 […] 조회로 고릅니다. 목록에 없으면 기준정보에 먼저 등록하세요.
  4. 개발유형은 체크박스입니다 — 사내설계 · 외주설계 · 사내조립 · 사외조립 중 해당하는 것을 모두 체크합니다. 외주설계를 체크하면 옆의 설계업체 칸이 열립니다(외주설계 협력업체에서 선택 또는 직접 입력).
  5. 견적가·수주가·네고조정/사유·사용재료·비고를 넣습니다. 공정이 여러 개면 금액은 공정 수로 나눠 저장되고, 다시 불러오면 합계로 보입니다.
  6. 📎 첨부파일: 관리제번을 넣은 뒤 [파일첨부] 또는 팝업에 파일을 끌어놓습니다(50MB까지, 한글 파일명 가능). 이미 등록된 수주면 즉시 반영되고, 새 수주면 [▤ 저장] 때 함께 저장됩니다.
  7. [▤ 저장] → 「수주등록 — 저장됨」 팝업이 뜨고 입력내용은 화면에 그대로 남습니다. 새 수주는 [＋ 신규등록]을 누릅니다.
💡 개발유형이 곧 발주 화면의 필터입니다: 외주설계 체크 → 설계외주발주에 나타남, 사외조립 체크 → SET외주발주에 나타남.
💡 설계업체·양산처는 제작계획등록의 설계처·양산처로 자동으로 이어집니다.
⚠ 외주설계를 체크하고 설계업체를 비워 두면 저장 전에 한 번 확인합니다.
⚠ 수주상태를 「취소」로 바꿀 때 이미 입고·확정된 발주가 있으면 취소되지 않습니다.

수주현황

등록된 수주를 관리제번 1줄로 요약해 봅니다(공정 제번은 「공정수 · 제번」 칸과 상세에서).

  1. 구분·수주유형과 검색 조건(관리제번·품번·도번·품명·고객사·양산처)을 넣고 [⌕ 검색].
  2. 행을 더블클릭(또는 [⌕ 상세보기])하면 수주 상세 팝업 — 개발유형·설계업체·양산처·첨부파일 링크와 공정별 견적가·수주가가 나옵니다.
  3. [✎ 수정]은 수주등록 화면을 그 관리제번으로 엽니다.
  4. 열 제목을 누르면 정렬, [▤ EXCEL]로 내려받습니다.

수주진척현황

관리제번마다 카드 1장으로 수주 → 제작계획 → 설계 → PartList → 구매 → 가공 → 조립 → 검사 → T/O → 납품 진행을 보여줍니다. 공정 제번(A·B·C) 중 가장 늦은 공정이 대표로 나옵니다.

  1. 관리제번·품명·고객사, 정렬(납기 임박순 등), 납품미완료로 거릅니다.
  2. 「다음 조치」 버튼(영업·설계·구매·가공·조립·품질·⚠지연)으로 담당별로 모아 봅니다.
  3. 카드를 누르면 공정별 보기가 펼쳐져 A·B·C 각각의 진행과 상세(계획일·담당·금액)가 나옵니다.
  4. 카드 아래 ↗ 화면 버튼으로 다음 조치 화면을 바로 엽니다.
  5. ✕ 진행삭제(관리자): 관리제번과 그 모든 공정 제번의 모든 이력(수주·계획·발주·입고·실적·PartList·경비 등)을 지웁니다. 확인창에 지울 공정 제번 목록이 나오고, 관리제번을 한 번 더 입력해야 실행됩니다.
⚠ 진행삭제는 되돌릴 수 없습니다. 테스트·오등록 제번 정리에만 쓰세요.

제번종합현황

제번 하나의 영업 → 설계 → 구매 → 가공 → 조립 → 납품 기록을 한 화면에 모아 봅니다. 회의·보고 때 한 금형의 전체 이력을 확인하는 용도입니다.

제작계획등록

영업에서 쓰던 제번관리 엑셀과 같은 모양입니다 — 기본정보 · 금형제작 EVENT(요구/목표/가능 일정) · 제품 형상 · 진척현황 · 특기사항 · 금액.

  1. 제작제번을 입력하거나 고르면 수주정보(품번·도번·품명·고객사·수주가)가 자동으로 채워집니다. 기존 계획이 있으면 그 계획이 불려옵니다.
  2. 기본정보에 제작구분(신규제작·수정·추가), 조수, 재질·두께(예 GI 2.0T), 사이즈(예 W150·P46), 고객담당, 설계처·제작처·양산처를 적습니다. 양산처·설계처는 수주등록의 양산처·설계업체가 자동으로 채워지며(비어 있을 때), 드롭다운에서 고르거나 직접 고칠 수 있습니다.
  3. 금형제작 EVENT 표는 접수·설계·가공·조립·초품·완료 6단계 × 3줄입니다. 요구일정은 고객이 요구한 날, 목표일정은 우리 계획(현황·진척 화면이 쓰는 기준), 가능일정은 지금 예상입니다. 가능일정이 목표보다 늦으면 칸이 노랗게, 빠르면 연두로 칠해집니다 — 엑셀에서 손으로 칠하던 표시입니다.
  4. 날짜 칸 위에서 마우스 휠을 굴리면 하루씩 바뀌고, 같은 줄의 오른쪽 일정(이후 공정)도 같은 만큼 함께 밀립니다. Shift+휠은 7일씩, Alt+휠은 그 칸만 바꿉니다. 새 제번을 열면 EVENT 표의 모든 날짜 칸이 오늘로 미리 채워지므로 휠로 밀어 가며 잡으면 됩니다. 기존 계획에서 빈 칸을 채우려면 요구일정 줄 오른쪽의 [오늘로]를 누르세요. 날짜 칸 오른쪽에는 요일이 (수)처럼 붙어 나오며 토요일은 파랑, 일요일은 빨강입니다. 제작계획현황 목록의 날짜도 9/23(수) 식으로 요일이 붙습니다. 현황 위쪽 검색칸은 제번·품번 기준이며, 품번 칸에서 고르면 그 제번으로 바로 조회됩니다. 목표일정의 접수는 제작계획에 입력한 날짜를 쓰며, 비어 있으면 수주일로 채워집니다.
  5. 같은 표 아래 줄에 설계·가공·조립의 시작일과 담당자, 가공의 사내/외주와 외주업체를 넣습니다. 일수는 자동 계산됩니다.
  6. 제품 형상 칸을 클릭해 그림(PNG·JPG)을 올립니다. 엑셀의 3D 그림 칸과 같습니다.
  7. 진척현황은 날짜와 내용을 넣고 [＋ 추가] — 엑셀의 ● 메모입니다. 날짜순으로 정렬되고 ✕ 로 지웁니다.
  8. 구성비 금액을 입력하면 목표가·이익률이 자동 계산됩니다. [▤ 저장]을 눌러야 전부 DB에 들어갑니다.
  9. 설계외주·조립외주 여부와 업체는 수주등록의 개발유형·설계업체를 따르고, 설계외주발주·SET외주발주에서 발주하면 자동으로 바뀝니다. 가공 외주만 여기서 지정합니다.
💡 수주가 대비 목표가 이익률을 보며 금액을 조정하세요.

제작진행현황

세워둔 제작계획을 제번관리 엑셀 시트처럼 한눈에 봅니다 — 제번마다 요구/목표/가능 3줄, 제품 그림, 진척현황, 특기사항.

  1. 제번·품명(품번·품명 포함) 칸에 입력하는 즉시 목록이 걸러집니다. 지연만을 켜면 가능일정이 목표보다 늦은 제번만, 완료 숨김을 켜면 완료 목표일이 지난 제번을 감춥니다.
  2. 가능일정이 목표보다 늦은 칸은 노랑, 앞당긴 칸은 연두입니다. 제번 아래 「지연 +N일」 표시는 여섯 단계 중 가장 많이 늦은 일수입니다.
  3. 진척현황은 최근 3건만 보이고, 전체는 더블클릭 상세에서 봅니다. 제품 그림을 클릭하면 크게 열립니다.
  4. 행 선택 → [⌕ 상세보기](또는 더블클릭) → 계획 상세 팝업.
  5. 팝업의 [▤ 수정]을 누르면 제작계획등록 화면이 해당 제번으로 열립니다. 값 수정 후 저장.
  6. [✕ 삭제]는 계획만 지우고 수주정보는 남깁니다.
  7. [▤ EXCEL]로 목록을 내려받습니다.

설계외주발주

설계를 외주업체에 맡길 때 관리제번 단위로 발주합니다.

  1. 제번리스트에는 수주등록에서 외주설계를 체크한 관리제번만 나옵니다(기본 [✓ 외주설계만]). 체크를 풀면 전체가 보입니다.
  2. 관리제번을 고르면 수주등록의 설계업체(또는 제작계획 설계처)가 협력업체리스트에서 자동 체크됩니다.
  3. 발주일·입고요구일·견적가·네고가를 넣고 [⬇ 요청추가] → [▣ 발주등록].
💡 여기서 등록한 발주가 설계외주입고의 처리 대상이 됩니다.

설계외주입고

외주설계의 진척률과 입고(납품)를 관리합니다. 진척률 100% = 입고확정.

  1. [⌕ 조회] 후 발주를 클릭해 선택합니다(관리제번·협력업체·미입고만으로 거르기).
  2. 입고일·진척률(%)·입고금액·검수자를 넣고 [▣ 입고처리].
  3. 입고일 확인창이 뜹니다 — 관리제번·업체·입고일(요일)·진척률·금액을 확인합니다. 입고일이 오늘보다 뒤이거나 30일 넘게 전이면 ⚠ 표시가 붙습니다. [취소]하면 입고일 칸으로 돌아갑니다.
  4. 부분 납품은 50·70처럼 여러 번 나눠 처리하고, 100%로 처리하면 금형원가내역의 공통비(외주설계)에 잡힙니다.
  5. 착오 시 입고 이력을 체크하고 [↶ 입고취소].
⚠ 입고금액 누계가 네고가를 넘으면 경고가 뜹니다.

설계외주현황

외주설계 발주의 진행 상태를 봅니다.

  1. 구분(전체/발주/입고)·관리제번·품명·품번·기간으로 [⌕ 조회].
  2. 행 더블클릭 → 입고(진척) 이력 팝업.
  3. 오발주는 행 선택 → [✕ 발주취소](입고 이력이 없을 때만).

SET외주발주

SET(조립) 외주를 관리제번 단위로 발주합니다. 설계외주발주와 같은 방식입니다.

  1. 제번리스트에는 수주등록에서 사외조립을 체크한 관리제번만 나옵니다(기본 [✓ 사외조립만]).
  2. 관리제번을 고르고 협력업체를 체크 → 발주일·입고요구일·견적가·네고가 → [⬇ 요청추가] → [▣ 발주등록].
💡 협력업체 목록은 기준정보의 SET 협력업체입니다.

SET외주입고

SET외주의 진척률과 입고를 관리합니다. 설계외주입고와 같은 방식이며, 진척률 100%가 입고확정입니다.

  1. 발주 선택 → 입고일·진척률·입고금액·검수자 → [▣ 입고처리] → 입고일 확인창에서 확인.
  2. 확정된 금액은 금형원가내역의 공통비(SET외주)와 매입현황(SET외주)에 잡힙니다.

SET외주현황

SET외주 발주의 진행 상태를 봅니다. 설계외주현황과 같은 방식입니다(더블클릭 이력, [✕ 발주취소]).

설계관리설계 실적과 PartList

설계실적등록

조립실적등록과 같은 격자 구조입니다. 행 = 선택 제번의 PartList 부품 + 「★ 금형 전체」(레이아웃·전체 설계), 칸 = 설계 한 공정. 칸을 우클릭해 설계자·인원·시간을 넣으면 설계비 사내(분 ÷ 60 × 인원 × 단가, 작업단가 DSN)가 design_results(설계·사내)에 쌓여 금형원가내역의 공통비(사내설계)에 반영됩니다. 체크한 부품 함께 등록(시간 나눔/같은 시간), ✕ 삭제, [↗ 설계실적조회]로 목록 확인.

  1. 제번리스트(진행/완료, 제번·품번 검색)에서 제번을 고르면 부품이 펼쳐지고, 제번 줄에 설계완료예정·누적 h·설계비가 보입니다.
  2. 부품의 설계 칸 우클릭 → 작업일·설계자·인원·시간(분)·단가·비고 → [✔ 실적 등록]. 같은 부품에 여러 날 누적됩니다.
  3. 외주설계는 이 화면이 아니라 외주설계발주·입고에서 금액으로 잡힙니다(설계비 사외).
💡 실적은 설계실적조회에 즉시 반영되고 사내 설계비 원가의 근거가 됩니다.

  3. [▤ EXCEL]로 내려받습니다(설계업체 포함).

PartList 등록(원재료)

도면이 나오면 공정별 원재료 소요를 등록합니다. 구매관리 '원재료 발주'의 자재표가 됩니다.

  1. 제번을 입력하고 [⌕ 검색] — 기존 등록분과 공정 목록이 뜹니다.
  2. 상단 '제번/공정' 표에서 공정을 클릭해 선택합니다.
  3. 하단 입력줄에 공정·품번·품명·재질·두께·길이·폭·수량·규격·등록자를 입력하고 [▤ 저장]. 한 줄씩 반복합니다.
  4. 엑셀 없이 한 건씩 넣을 때는 [＋ 수동등록]: 품번·품명·재질·규격·두께·수량을 입력하고 [⬇ 리스트에 추가] — 창을 열어둔 채 계속 입력할 수 있습니다. 추가된 행은 미등록으로 올라오므로 체크 후 [▤ 등록]을 눌러야 저장됩니다.
  5. 대량 입력은 [▤ 엑셀불러오기]: 엑셀에서 '공정·품번·품명·재질·두께·길이·폭·수량·규격·비고' 순서로 열을 맞춰 복사 → 붙여넣기 → [등록]. 첫 행이 제목이면 자동으로 건너뜁니다.
  6. 형태(사각·환봉·파이프·판재)를 고르면 중량이 형태에 맞게 계산됩니다. 사각은 두께×길이×폭, 환봉은 Ø×길이, 파이프는 외경·내경·길이로 계산됩니다(참고용 — 원재료 발주 금액은 단가 × 수량).
  7. 부품 그림은 행을 체크하고 [📷 이미지] → 그림 파일을 고르면 올라갑니다(8MB 이하). 올린 그림은 📷 칸에 작게 보이고, 클릭하면 크게 열립니다. 사내외가공 발주의 부품 그림·그림보드에도 같은 그림이 나옵니다.
  8. 삭제는 행 체크 → [✕ 삭제].
  9. [📷 이미지] — 행을 하나 체크하고 누르면 부품 그림 편집기가 뜹니다. 캐드 화면을 캡쳐(Win+Shift+S)한 뒤 창에서 Ctrl+V로 붙여넣거나 파일을 끌어다 놓으면, 검은 바탕은 자동으로 흰 바탕(흑백·출력용)으로 바뀌고 A4 크기(세로/가로 자동)에 제번·부품·품명·규격·일자 머리글과 함께 배치됩니다. 화살표·사각·원·자유선·글자로 표시를 넣고(색·굵기·글자 크기 선택, ↶ 되돌리기) [▣ 저장(등록)]하면 부품 이미지로 등록되어 작업표지·금형원가·발주서에 함께 나옵니다. [🖨 인쇄(A4)]·[⬇ PNG]도 가능. 바탕을 「컬러 반전」이나 「원본 그대로」로 바꿀 수 있습니다.
💡 같은 제번+공정+품번을 다시 저장하면 수정으로 동작합니다.
⚠ 미등록 제번으로 저장하면 실패합니다. 수주등록부터 하세요.

💡 .xls·.csv 는 취소선을 읽지 못합니다. 미리보기에서 취소 행을 확인하거나 .xlsx로 저장해 쓰세요.

원재료 발주

PartList(원재료)를 협력업체에 발주합니다.

  1. 제번리스트에서 제번을 고르면 PartList(원재료)가 자재표로 뜹니다.
  2. 협력업체를 고르고, 발주할 품번을 체크 → 입고요구일 → [⬇ 요청추가].
  3. 구매요청 리스트에서 발주수량·매입단가를 확인합니다. 매입금액 = 매입단가 × 발주수량입니다(중량은 쓰지 않습니다).
  4. [▣ 저장] → 발주 확정, 발주서 메일 창이 뜹니다.
  5. 자재표 행을 우클릭하면 그 자리에서 발주·입고·입고확정 창이 열립니다. 여러 품번을 체크해 두고 우클릭하면 함께 처리됩니다.
  6. 처음부터 다시 구매할 품번은 [↻ 신규진행](사유 선택)으로 새 차수를 시작합니다. 같은 차수 안의 수량 추가는 [↻ 재발주].
💡 단가는 개당(장당) 금액으로 넣습니다. 입고확정 때 단가·네고율로 확정가가 다시 정해집니다.

원재료 입고

발주한 원재료의 입고를 처리합니다.

  1. [⌕ 검색]으로 미입고 발주를 불러옵니다(입고완료 포함 체크로 전체).
  2. 입고된 행을 체크(제목 칸 = 전체 선택) → 입고일·입고수량 → [▣ 저장].
  3. 잘못 처리는 [✖ 입고취소], 발주 자체가 무효면 [✖ 발주취소].

원재료 입고확정

입고된 원재료의 금액을 확정합니다. 확정된 금액만 원가에 들어갑니다.

  1. 상단 협력업체 · 관리제번 · 제번 · 품명(모두 드롭다운/입력)으로 거릅니다. 관리제번을 고르면 A~F 공정 제번이 모두 나옵니다.
  2. 확정할 행을 체크합니다(제목 칸 체크 = 전체 선택).
  3. 입고수량과 단가를 넣으면 매입가 = 입고수량 × 단가가 자동 계산됩니다.
  4. 하단 네고율 → [네고율 적용]을 누르면 확정가 = 매입가 × (1 − 네고율). 네고율로 안 떨어지는 금액은 표의 확정가 칸에 직접 넣거나, 하단 확정가 칸 → [확정가 적용]으로 선택 행에 일괄 입력합니다.
  5. 입고확정일을 확인하고 [▣ 입고확정] → 「저장됨」 팝업.
  6. 잘못 확정한 건은 [완료]로 조회 → 체크 → [✖ 입고확정취소].
💡 단가는 발주 때 넣은 단가를 불러오고, 여기서 고치면 함께 저장됩니다. 단가가 없는 옛 발주는 저장된 매입가를 그대로 보여줍니다.

원재료 발주·입고·확정 상태를 봅니다.

  2. 끝 열에 매입가(수량×단가) · 네고율 · 확정가가 나오고 합계줄·EXCEL에도 포함됩니다.
  3. 체크한 입고확정 건은 [입고확정취소]로 「입고」 상태로 되돌릴 수 있습니다.

구매품 발주

PartList의 구매품을 발주합니다. 원재료 발주와 같은 방식입니다.

  1. 제번 선택 → 자재표 체크 → 협력업체 선택 → [⬇] → 기준단가/매입단가 확인 → [▣ 저장] → [⎙ PRINT]로 발주서 인쇄.
  2. 여러 품번 한 번에 — 자재표에서 품번을 체크해 두고 그중 한 줄을 우클릭하면 열리는 창(발주·입고·입고확정)이 체크한 품번 전부에 함께 적용됩니다. 발주창에는 함께 발주할 품번 표가 붙고, 수량·단가·금액(견적가)을 품번별로 각각 고칠 수 있습니다(처음엔 잔량·업체별 단가 이력으로 자동 채움, 손으로 고친 값은 노랑). 확정가는 입고확정 때 네고율로 잡힙니다. 입고는 각 발주 잔량·발주단가로 같은 입고일에, 입고확정은 이 창의 확정일·네고율을 각 매입가에 적용합니다. 창 안의 초록 안내줄과 버튼의 (+N)으로 몇 개가 함께 처리되는지 보입니다. 발주완료 품번도 체크할 수 있어 입고·확정을 묶어 처리할 수 있습니다. 한 품번을 여러 업체에 나눠 발주한 경우(발주 내역 N건 창)에도 줄마다 체크가 있어 [▣ 입고 처리 (체크)]·[✖ 발주취소 (체크)]로 체크한 발주건을 한 번에 처리합니다.
  3. ✉ 발주서 메일 — 발주를 등록하면 바로 발주서 메일 창이 뜹니다. 받는 사람은 기준정보 › 협력업체관리의 이메일이 자동으로 들어가고, 발주 내역표와 PartList에 등록한 부품 그림(A4)이 함께 갑니다. [✉ 보내기]는 구글 앱스 스크립트 웹앱을 통해 회사 구글 계정으로 바로 발송(발주서 PDF + 부품 그림 첨부, 기록은 mail_log), 함수가 아직 없으면 [📨 메일 앱]으로 메일 프로그램을 열고 [🖨 발주서(A4)] 창을 PDF로 저장해 첨부하면 됩니다. 발주 뒤에도 그 공정(품번) 칸을 우클릭해 열리는 입고·확정·완료 창의 [🧾 발주서]로 그 부품의 발주서(같은 업체·발주일 발주건만)를 언제든 다시 열 수 있습니다.
💡 매입단가는 그 업체의 최근 발주 단가가 자동으로 붙고, 발주창에서 고칠 수 있습니다.

  1. 제번·품번 조건을 넣고 [⌕ 카드조회] — 기준공정이 전개된 카드가 미리보기로 뜹니다.
  2. 내용 확인 후 [▣ 카드발행] — 카드번호가 확정되고 QR코드가 새겨집니다.
  3. [🖨]로 인쇄해 제품에 부착합니다. 2페이지는 검사기록란(최대 4회차)입니다.
  4. 공정 완료 시 현장에서 완료일·검사값을 기재하고 다음 공정으로 인계합니다.

사내외가공 발주

부품별 가공공정을 한 표로 보고, 칸을 우클릭해 발주 → 출고 → 입고 → 입고확정까지 처리합니다. 사내 공정은 가공시간을 등록합니다.

  1. 관리제번·제번을 고르면 부품이 행으로(PartList 원재료 등록 순서), 가공공정이 공정1~10 칸으로 펼쳐집니다. 가공계획이 없는 부품은 가공 기준공정 순서로 나옵니다.
  2. 칸 색: 초록 ▶ 다음 = 지금 발주할 공정, 보라 = 요청, 주황 = 출고(발주됨), 파랑 = 입고, 회색 = 완료, 갈색 사선 = 사내.
  3. 외주 칸 우클릭 — 미발주면 발주창, 출고면 입고창, 입고면 확정창. 연속 공정을 한 업체에 맡기려면 칸을 눌러 범위를 잡고 마지막 칸을 우클릭(묶음 발주).
  4. 다음 공정은 직전 외주 공정이 입고(또는 확정)돼야 발주됩니다. 입고확정은 나중에 해도 진행을 막지 않습니다.
  5. 사내 칸 우클릭 → 완료일·작업자·설비·가공시간(분) → [✔ 가공완료 등록]. 가공비 = 시간 ÷ 60 × 작업단가.
  6. 그림보드: 부품 행(그림·부품코드·부품명)을 우클릭하거나 그림을 클릭. 오른쪽에서 공정을 순서대로 눌러 띠를 만들고 [▣ 가공계획 적용] → 결과가 그림보드 창에 뜹니다. 이미 발주된 공정이 있으면 확인 후, 발주 이력이 새 순서의 같은 공정 자리로 옮겨집니다.
  7. 그림보드의 QR을 인쇄해 부품에 붙이면, 현장·협력업체가 휴대폰으로 읽어 작업완료(외주=입고, 사내=가공실적)를 등록합니다. QR은 차수마다 다릅니다.
  8. 처음부터 다시 가공할 부품은 [↻ 신규진행]으로 새 차수를 시작하고, [⚙ 차수 관리]에서 되돌리기·종료합니다. 최종완료는 상단 「최종완료 제외/포함」으로 숨깁니다.
💡 그림보드에 「⚠ 가공계획 미저장」이 보이면 [가공계획 적용]을 한 번 눌러 저장하세요. 저장 전 QR은 발주된 공정만 보여줍니다.
💡 화면을 바꾼 뒤에는 발주 화면과 그림보드를 모두 새로고침(Ctrl+F5)하세요.

조립관리조립 실적과 검사

조립실적등록

사내외가공 발주와 같은 격자 구조입니다. 행 = 선택 제번의 PartList(원재료) 부품 + 「★ 금형 전체」 행, 칸 = 랩핑,조립 한 공정. 칸을 우클릭해 작업자·인원·시간을 넣으면 조립비(분 ÷ 60 × 인원 × 단가)가 design_results(조립)에 쌓여 금형원가내역에 반영됩니다.

  1. 제번리스트에서 제번을 고르면(진행/완료 라디오, 제번·품번 검색) 오른쪽에 부품이 펼쳐집니다. 제번 줄에 누적 시간·조립비·검사횟수가 보입니다.
  2. 부품의 랩핑,조립 칸을 우클릭(또는 더블클릭) → 작업일·작업자(사용자정보)·인원·시간(분)·단가(작업단가 AS → 조립 ASM 순)·비고를 넣고 [✔ 실적 등록]. 같은 부품에 여러 날 누적되며, 창 아래 목록에서 ✕ 로 한 건씩 지우거나 [↺ 전체 취소]로 모두 지웁니다.
  3. 합형·T/O 처럼 특정 부품에 매지 않는 시간은 맨 위 ★ 금형 전체 행에 넣습니다.
  4. 여러 부품을 체크해 두고 한 칸을 우클릭하면 체크한 부품에 함께 등록됩니다 — 넣은 시간을 부품 수로 나눠 넣거나(기본) 각 부품에 같은 시간으로 넣을 수 있습니다.
  5. 칸 색: 연한 갈색 = 미등록, 진한 갈색 = 실적 있음(누적 h · 원 · 건수). 「최근 작업」 열에 마지막 작업일·작업자.
  6. [▣ 조립 완료] — 제번 조립 완료 처리(완료 목록으로 이동). [검사시트 작성/수정] — 검사횟수 +1, 검사실적등록의 조립검사 대상 생성. [▤ EXCEL] — 실적 전체 내려받기.
  7. 금형원가(내역) 화면의 「랩핑,조립 사내」 칸과 같은 자료를 공유하고, 제조원가 조회 내역표의 「조립·검사비 › 조립」 열에 잡힙니다. 단가는 작업단가의 COM(랩핑,조립) → ASM(조립 공통) 순.

검사실적등록

조립실적등록과 같은 격자 구조입니다. 행 = PartList 부품 + 「★ 금형 전체」, 칸 = 검사.

  1. 제번을 고르고 부품의 검사 칸을 우클릭 → 작업일·검사자·인원·시간(분)·단가 → [✔ 실적 등록].
  2. 검사비 = 분 ÷ 60 × 인원 × 단가(작업단가 INS). 금형원가내역의 공통비(검사)·부품 공정 칸에 반영됩니다.
  3. 여러 부품을 체크해 두고 한 칸을 우클릭하면 함께 등록(시간 나눔/같은 시간)됩니다.

  1. 관리제번 ▼ · 제번 ▼을 고릅니다. 「관리제번 전체」를 체크하면 A·B·C 공정을 한 표에 모읍니다.
  2. 부품 줄: 입고일·품번·부품명·재질·형태·규격·단가·수량·원재료비·구매품비, 공정 칸(위 = 사내 시간 h, 아래 = 외주 확정금액 원, 괄호 = 미확정), 가공비·합계.
  3. 표 아래 금형 공통비: 외주설계 · SET외주 · 사내설계 · 조립(금형 전체) · 검사(금형 전체) · 경비 · 기타(부품 미지정).

💡 금액은 모두 입고확정된 확정가 기준입니다. 확정 전 금액은 괄호(회색)로만 보이고 합계에 들어가지 않습니다.

  1. 구분(기본 외주가공)·기간(입고확정일 기준)·상태(기본 입고확정만)를 정하고 [조회]. [이번 달]·[지난 달]·[올해] 버튼으로 기간을 바로 잡을 수 있습니다.
  2. 집계를 「업체 × 월별」이나 「업체 × 제번별」로 바꾸면 그 단위로 나뉩니다. 비중은 확정금액 합계 대비입니다.
  3. 합계 행을 클릭하면 아래에 발주 내역(제번·품번·공정·금액)이 나옵니다. [EXCEL]로 내보냅니다.
  4. 확정금액 규칙: 확정가가 있으면 확정가, 없으면 견적가 × (1 − 네고율).
